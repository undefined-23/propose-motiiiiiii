# For Motiiiiiiiiiii ❤️

A mobile-first interactive proposal website for Sagarika.

## Files
- `index.html` — page structure/content
- `styles.css` — mobile-first design and animations
- `script.js` — interactions, music, clues, stars and celebration
- `assets/photo-1.jpg` ... `photo-7.jpg` — supplied photos
- `assets/gerua.mp3` — **not included**; add a legally obtained/authorized audio file if you want local playback.

## Run locally
Open `index.html` in a browser. For the most reliable behavior, use a local static server (for example VS Code Live Server).

## GitHub Pages
1. Create a GitHub repository.
2. Put all files/folders in the repository root.
3. Commit and push.
4. GitHub → Settings → Pages → Deploy from branch → `main` / root.
5. Open the generated Pages URL on your phone.

## Before sending her the link
- Test the complete flow on Android Chrome.
- Test the music after adding `assets/gerua.mp3`.
- Test on mobile data, not only Wi-Fi.
- Replace any wording you want to make more personal.
